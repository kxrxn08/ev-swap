# EV Swap Marketing Landing Page

Presentation-ready React + Vite single-page prototype for an EV battery swapping / rental business.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Before presenting

1. Replace `919999999999` in `src/main.jsx` with the real WhatsApp/phone number.
2. Replace placeholder hub names and map links.
3. Attach the actual partnership PDF to the partnership-brief button.
4. Replace pilot testimonials with verified quotes.
5. Replace placeholder pricing with your pilot pricing.

The marketing numbers in the campaign funnel are explicitly labelled as illustrative targets.
